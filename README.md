# YOURKA

## YOURich Keyboard Assistant

Локальный помощник раскладки клавиатуры Windows для CAD и профессиональных приложений.

## Зачем нужен YOURKA

При работе в Rhino, ZBrush, Materialise Magics и других CAD-системах русская раскладка Windows меняет поведение цифровой клавиатуры:

- десятичная точка `.` превращается в запятую `,`
- координаты и параметры вводятся неправильно
- приходится останавливать работу, переключать язык и вводить заново

YOURKA решает эту проблему автоматически.

## Основная функция

YOURKA отслеживает активное приложение и при переходе в рабочую среду автоматически включает нужную раскладку.

Примеры профилей:

- Rhino → English
- ZBrush → English
- Materialise Magics → English
- ArtCAM → English

## Дополнительная функция

YOURKA также умеет исправлять текст, набранный в неверной раскладке:

- автоматический режим
- ручной режим
- горячая клавиша `Alt+F9`
